GeoTrips VK Helper

Получение одноразового кода для серверной авторизации VK. Код нужен, чтобы GitHub получил пользовательский токен, пригодный для загрузки обычных фотографий на стену сообщества.

Защищённый ключ приложения здесь не используется и на эту страницу не передаётся.

VK откроется в новой вкладке. Разрешите доступ к фотографиям, после чего вы вернётесь на эту страницу.

Код получен ✅

Этот код одноразовый и быстро истекает. Сохраните его в GitHub Secrets под именем VK_AUTH_CODE. Сам код в чат не присылайте.
