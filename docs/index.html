GeoTrips VK Photo Connect

Однократное подключение автоматической загрузки нативных VK photo… из карточек Tripster.

Сообщество: 241800139
OAuth: пользовательский токен
Право: photos
Callback: https://oauth.vk.com/blank.html

Проверяю подключение…

1. Разреши доступ к фотографиям

Нажми кнопку. VK откроется в новой вкладке. Подтверди право photos для своего аккаунта — это нужно серверу для photos.getWallUploadServer.

2. Заверши подключение

После подтверждения VK откроет blank.html. Скопируй полный адрес из адресной строки, вернись сюда и вставь его ниже. Это URL с одноразовым code, не сам токен.

После успеха сервер сохранит пользовательский токен в зашифрованном виде. В GitHub Actions сам VK-токен не передаётся.
