GeoTrips Photo Helper

Регистрация ИП и кабинет VK ID Business не нужны. Для автозагрузки фото достаточно один раз дать этому мини-приложению доступ к фотографиям VK. Токен проверяется сервером и сохраняется в зашифрованном виде.

Подготовка нативных фото Tripster для 3 постов по Турции.

Используются уменьшенные фотографии Tripster (800×600 / 600×800), чтобы не повторялась ошибка image_too_large. Посты здесь НЕ публикуются.
